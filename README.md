# Run - Ferrari + Grok AI Driver

Modified infinite runner clone featuring a **Ferrari** (using the sports sedan model) and **Grok AI driver** enhancements.

Original by [tommhuth](https://github.com/tommhuth/run) - live at [run.huth.io](https://run.huth.io)

## Changes
- Player vehicle swapped from SUV to sports sedan (Ferrari-style)
- Traffic AI ("chicken" behavior) made more aggressive / Grok-inspired
- UI and titles updated to reflect Ferrari + Grok AI Driver
- All other mechanics, physics, assets, and gameplay kept the same

## Run locally
```bash
yarn install
yarn dev
```

Debug mode: add `?debug` to the URL.
